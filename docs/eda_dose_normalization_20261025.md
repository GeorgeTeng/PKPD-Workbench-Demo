# Mandatory dose-normalization assessment in EDA

Multi-dose concentration data previously had raw concentration plots without an enforced dose-normalization decision. EDA now records applicability for concentration-bearing tables, requires a selected derived plot for eligible source-bound comparison groups, and explains blocked, not-applicable or missing-metadata cases. The decision is carried through planning, coverage, rendering verification, handoff and the review portal.

The C(t)/Dose renderer retains raw operands, source coordinates, units, reported dose basis and censoring status. Python independently checks the R output arithmetic and provenance. Original concentration figures are retained. This is descriptive comparison, not a dose-proportionality test or model fit.

Contracts are intentionally source-specific. New or changed datasets need verified dose and comparison metadata; unknown datasets produce NEEDS_METADATA instead of inferred compatibility. Source restrictions and observation roles remain binding. This does not guarantee automatic grouping of arbitrary future datasets.

## Local result and rule coverage

The local review has 107 figures and 58 source tables. One new mouse SC plasma plot covers five doses and 39 points; the original 106 images and source tables are unchanged. Eleven verified single-dose scopes are not applicable to within-scope multi-dose comparison; two IT groups remain blocked by source restrictions. Unqualified concentration tables retain explicit metadata gaps.

Fifteen operative scientific drawing sections were compared with admitted tables and figure recipes. The [coverage summary](../validation/eda_dose_release_20261025/scientific_coverage_summary.json) records remaining conditions: incomplete cross-experiment PK-PD linkage, source restrictions, missing time series and undefined exposure windows. This is a source/caption/recipe audit, not a fresh pixel review of all historical figures or independent scientific ER.
