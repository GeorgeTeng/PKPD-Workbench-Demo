# 方法与适用边界

## 1. 与已有研究结构的关系

Sou 等的 apramycin 研究把临床前 PK 建模、跨物种外推和 PK/PD 分析衔接起来。本原型借鉴“先明确暴露，再连接反应”的模块结构，仅实现通用 PK 与指标/回归基础；没有复现该文完整模型，也没有导入其药物参数或宣称获得相同预测能力。[Sou et al., 2021, Clinical Pharmacology & Therapeutics, DOI: 10.1002/cpt.2104](https://ascpt.onlinelibrary.wiley.com/doi/10.1002/cpt.2104)

## 2. 指标的精确定义

给定明确窗口 `[a,b]`、浓度 `C(t)` 和同浓度单位的 MIC：

```text
AUC[a,b]     = integral_a^b C(t) dt
AUC/MIC     = AUC[a,b] / MIC                  # h
Cmax/MIC    = max(C(t), t in window) / MIC    # dimensionless
%T>MIC      = 100/(b-a) * integral_a^b I[C(t)>MIC] dt
```

`f` 表示在上述公式中使用游离浓度。只有常数 fu 有依据时，才使用 `C_free(t)=fu*C_total(t)`。MIC 必须匹配适用的药物/测定信息，程序不判断这种生物学可比性。

线性插值段用梯形积分。下降且两端浓度都为正时，可用对数线性插值；该段积分为 `dt*(C1-C0)/log(C1/C0)`。过阈值的时间使用相同插值求解。区间内等于 MIC 的平坦段不计为大于 MIC。

直接输入曲线时，窗口必须被数据覆盖。稀疏采样的最大值可能低于真正 Cmax。AUC 的时间单位是 h，不能把 AUC0–8/MIC 当作 AUC0–24/MIC；单次给药也不自动等于稳态。

模型曲线按给药起止时间分段；推注事件前后使用不同单侧浓度，避免跨跳变积分。模型积分窗口为 `[a,b)`，恰好 b 时给药不计入该窗口 Cmax。二房室或输注曲线的数值精度需用更小 `step_h` 检查。

## 3. 个体 PK

一房室静脉推注结构：

```text
C(t) = dose/V * exp(-(CL/V)*(t-t_dose)), t >= t_dose
```

有限输注通过对同一指数响应积分得到；多次剂量线性叠加。二房室使用中央/外周分布的双指数解析解，参数为 CL、Vc、Q、Vp。默认对正参数取 log 后拟合；结构假设为线性、时间不变的 PK。

拟合可选：

- `additive`：浓度尺度上独立、等方差高斯误差。
- `lognormal`：log 浓度尺度上独立、等方差高斯误差；要求浓度为正。

优化使用 `minpack.lm::nlsLM`。参数 CI 是基于局部协方差的近似，正参数在 log 参数尺度构造再反变换；不是预测区间。对数正态拟合输出的结构曲线是条件中位数。[nlsLM 官方文档](https://search.r-project.org/CRAN/refmans/minpack.lm/html/nlsLM.html)

二房室参数需要分布相和消除相的信息支持；多一个房室不保证在当前采样设计下可辨识。当前有收敛检查和协方差检查，但不能自动识别所有病态模型。

## 4. 群体纵向 PK

本版群体接口限定一房室、单次 t=0 静脉推注：

```text
log(CL_i) = log(CL_typ) + eta_CL_i
log(V_i)  = log(V_typ)  + eta_V_i
log(C_ij) = log(dose_i) - log(V_i) - CL_i/V_i * t_ij + epsilon_ij
```

两个 eta 当前用独立零均值正态随机效应；epsilon 为独立正态残差。这使同一个体的重复浓度共享个体 PK 参数。通过 `nlme::nlme`、ML 拟合。[nlme 官方文档](https://stat.ethz.ch/R-manual/R-devel/library/nlme/html/nlme.html)

程序的最低行数/个体数检查只是阻止明显不足的输入。科学样本量需要指定参数、变异度、采样时间、精度或预测目标后进行设计评价。这里没有完成这种样本量设计。

新个体预测使用典型参数、eta=0；已有个体可使用经验 Bayes 随机效应。两者都不是人群平均浓度，也不含个体间或残差预测区间。已有个体的条件拟合图通常比新个体预测乐观。

## 5. 指标—终点 Emax/Hill

```text
E(x) = E0 +/- Emax * x^h / (EC50^h + x^h)
```

EC50 与 x 的单位相同，Emax 与反应单位相同；默认 h=1，也可估计。程序采用多个初值、正参数变换及数值边界。固定 h 与自由 h 的选择需要数据支持，不宜仅因自由模型训练拟合更好就增加参数。

当前要求每个独立单位一个终点、终点含义一致，并用独立高斯误差拟合。指数值的估计误差、测定误差和研究异质性尚未作为潜变量建模。按研究整组留出比随机拆散同研究观测更接近检查组外预测，但只有来源适当的独立验证集才可作为外部验证。

## 6. 通用纵向反应

实现 `response ~ natural_spline(time) + exposure + random_intercept(subject)`。可选 `corCAR1` 用连续时间相关结构处理不等间隔观测。它描述条件关联；在暴露随时间变化且两者高度相关时，效应可能无法稳定区分。[lme 官方文档](https://stat.ethz.ch/R-manual/R-devel/library/nlme/html/lme.html)、[corCAR1 官方文档](https://stat.ethz.ch/R-manual/R-devel/library/nlme/html/corCAR1.html)

该接口没有模拟效应延迟、系统周转或其他具体药效机制。样条时间范围外的预测会被拒绝。

## 7. 输出应该如何解读

| 输出 | 能帮助判断 | 不能单独证明 |
|---|---|---|
| 参数 RSE / Wald CI | 当前模型和误差假设下的局部精度 | 真值一定落入某一次 CI、人体外推准确 |
| 训练 RMSE | 当前数据的拟合偏差 | 独立对象预测误差 |
| AIC / AICc | 同终点、同观测、同似然尺度的相对支持 | 机制正确、最佳指标通用 |
| 整组留出 RMSE | 已声明研究/批次之间的预测表现 | 跨物种预测已验证 |
| 参数恢复测试 | 在已知生成模型下程序能否恢复参数 | 真实系统符合这个生成模型 |

**不要直接比较 additive 与 lognormal 两种拟合的当前 AIC**：它们的响应尺度不同，当前输出没有统一原浓度尺度的 Jacobian 修正。群体模型的当前 AICc 也是以观测数计算的通用描述量，不作为聚类小样本可靠性准则。

本版未给“模型质量总分”，也没有预设 RSE<某值即可认为可靠。阈值应由具体研究决策、参数敏感性与独立预测需要决定。
